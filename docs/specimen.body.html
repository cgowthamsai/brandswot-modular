BRANDSWOT Modular

A pixel display typeface built from brickwork. Every pixel of the 5 × 7 grid holds three courses of running-bond masonry, so the letters read as built, not drawn. Free for everyone, including commercial work.

Type tester

Click into the wall and type. Weight changes the mortar, never the letter.

Style
Colour

Seven weights, one wall

Every weight shares identical spacing, so headlines can animate from Light to Black without reflowing.

How a pixel is laid

Grid
5 × 7 pixels for capitals, 5 rows for x-height, 2 rows of descender
Pixel
100 × 99 units: three brick courses
Brick
40 × 23 units at Bold, laid in running bond
Mortar
10 units at Bold · 22 at Light · 2 at Black
Em
1000 units · cap height 695 · x-height 497
Italic
Same bricks sheared 12°

Install

Desktop files for design apps, a CDN link for websites, and an npm package for React, Vite and Next.js projects.

Desktop

Download the zip, open otf/, select all files and install. Works in Figma, Word, Photoshop, Illustrator, InDesign, Premiere and Canva (upload).
