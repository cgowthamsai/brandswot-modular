## BRANDSWOT Modular v2.100

- Variable weight axis, Light 300 → Black 900, plus Italic
- Google Fonts Latin Core character set (310 characters, all European Latin accents)
- Proportional spacing for narrow letters
- Web fonts (WOFF2), desktop fonts (OTF/TTF), variable fonts
- SIL Open Font License 1.1 — free for commercial use

**Install:** download `BRANDSWOT-Modular-v2.100.zip` below → open `otf/` → select all → Install.
